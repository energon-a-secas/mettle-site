# CLAUDE.md — Mettle

Mettle — reasoning maturity probe; chained failure/recovery questions score reasoning depth across five virtues, fully local (mettle.neorgon.com)

**Live:** mettle.neorgon.com · **Port:** 8847

## Run

```bash
make serve
```

Then open http://localhost:8847. It must be served over HTTP — the app is ES modules, and `file://` blocks them.

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- No single JS file over ~500 lines. It currently holds.
